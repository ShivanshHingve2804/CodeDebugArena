# Local agent evaluation dashboard

The dashboard starts a loopback-only Python web server and evaluates local CLI agents or compatible model APIs with the actual CodeDebugArena challenge tests.

## Start

From the repository root, install pytest and run the server:

```powershell
python -m pip install -e ".[dev]"
python web/server.py
```

Open <http://127.0.0.1:8000>. Stop the server with Ctrl+C.

## Configure an agent

Choose a connection type for each agent: Codex CLI, Claude Code, Hermes CLI, an OpenAI-compatible API, or Advanced CLI. Built-in CLI commands are generated by the server; only Advanced CLI requires a command containing `{prompt}`. The model name or ID is stored with each run for the live page, report, and CSV export. The Hermes preset runs the configured Hermes CLI model and provider; set those in Hermes first. Its model-name field is for labeling the benchmark results.

```text
codex exec --skip-git-repo-check --approve-for-me "{prompt}"
claude -p "{prompt}"
hermes chat --oneshot -q "{prompt}"
```

For Google AI Studio, use the **Google Gemini Pro** preset, enter an AI Studio API key, and verify your account can access `gemini-3.1-pro-preview`. Its base URL is `https://generativelanguage.googleapis.com/v1beta/openai/`; the dashboard calls the documented `/chat/completions` route. Google model IDs and access can change, so check the current [Gemini model list](https://ai.google.dev/gemini-api/docs/models).

The OpenAI-compatible API option accepts a base URL and model ID, sends the challenge and current source, and writes the returned complete Python file into the isolated challenge workspace. HTTP is allowed only for localhost; remote endpoints must use HTTPS. API keys are kept in browser memory for the session, sent only to the local runner and API endpoint, and omitted from run results. Advanced CLI commands run without a shell; authenticate the CLI before starting an evaluation.

On Windows, if `codex` is not on the server's `PATH`, the runner also checks the current user's `%LOCALAPPDATA%\OpenAI\Codex\bin\*\codex.exe` installation automatically.

After the run starts, the dashboard opens the live execution page in the same tab. Use **Stop evaluation** there to terminate the active CLI process and end the run. The live page stays open with completed results from the partial run.

## What an evaluation does

For each selected agent and challenge, the server creates a fresh temporary directory containing `buggy.py` and the challenge README. The agent is asked to edit only `buggy.py`; the trusted `test_challenge.py` is copied into the directory only after the agent exits. Pytest then evaluates the fix with `CHALLENGE_TARGET=buggy`. The dashboard reports actual pass/fail outcomes, agent time, test time, and changed lines. Temporary challenge workspaces are removed after each evaluation. Run history stays in memory until the server stops.

CLI agents run on the host with the same permissions as the user running the server. API agents receive the selected challenge instructions and source code at the configured endpoint. Use only trusted CLIs and API endpoints. The agent timeout is three minutes per challenge; test execution is limited to twenty seconds. The server binds to `127.0.0.1` by default.
